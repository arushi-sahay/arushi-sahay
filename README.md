## Projects

### [HNSW Vector Search in C](https://github.com/arushi-sahay/hnsw-vector-search-c)

An implementation of Hierarchical Navigable Small World (HNSW) for approximate nearest-neighbour search in C. Explores graph construction, vector search, pretrained sentence embeddings, and benchmarking. Originally built to understand the algorithm beyond using an existing library.

### ICME Detection using Machine Learning

Exploring different classical ML and deep learning approaches for ICME classification and event-level detection using OMNI solar wind observations. Also investigating detection duration, false positives, and cross-instrument generalization using Aditya-L1 SWIS and MAG measurements.

*Currently an exploratory project being extended towards research.*

### [Knowledge Distillation Research Implementations](https://github.com/arushi-sahay/distillation-research-implementations)

A growing collection of implementations of knowledge distillation research papers, with individual paper documentation and reproducible workflows.
